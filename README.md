# RVCE Events — IEEE Student Branch

Live demo: https://saitriveni23.github.io/IEEE-RVCE-frontend-/

A single-page application for browsing RVCE campus events built for the IEEE Student Branch Web Development Hiring Challenge 2026.

## Features
- Browse 11,950+ campus events
- Search, filter by category, sort
- Event detail page with full info
- Bookmark events (saved locally)
- Handles messy real-world data gracefully
